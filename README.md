# 🌸 Real-Time Hand Gesture Flower Controller

A web-based interactive project that uses your webcam to detect hand gestures in real-time and controls a virtual flower's growth and movement on screen. Built with HTML, CSS, and JavaScript, this project demonstrates how hand-tracking can be used to create fun, gesture-driven visual experiences directly in the browser.

## ✨ Features
- Real-time hand gesture detection using webcam input
- Interactive flower animation that responds to hand movements
- Lightweight, runs entirely in the browser — no installation needed

## 🚀 Live Demo
[Click here to try it](https://bhumipawar0210-cmyk.github.io/-A-Real-Time-Hand-Gesture-Flower-Controller/)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📸 How to Use
1. Open the live demo link above
2. Allow camera access when prompted
3. Move your hand in front of the camera to control the flower
